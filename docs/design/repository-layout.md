# Repository Layout

Status: Accepted
Related RFCs: RFC-0008, RFC-0015 (primary), RFC-0017
Related ADRs: ADR-0006
Related docs: [artifact-format.md](artifact-format.md), [storage-design.md](storage-design.md), [repository-lifecycle.md](repository-lifecycle.md)

## Purpose

Defines the on-disk layout of a Functor repository for the CLI MVP. The layout is projection independent, human-readable where practical, portable across platforms and friendly to version control.

## Repository Root

A directory is a Functor repository if it contains `.functor/repository.toml`. The CLI discovers the repository by walking up from the current directory (or from `--repo <path>`).

## MVP Layout

```text
my-repository/
├── .functor/
│   ├── repository.toml
│   └── lock                      # created on demand while writing; ignored by git
├── artifacts/
│   ├── .gitkeep
│   └── art_01J9Z3K8M2Q7X4V6B5N1R0T8WD.toml
├── relationships/
│   ├── .gitkeep
│   └── rel_01J9Z3KQ0A1B2C3D4E5F6G7H8J.toml
├── events/
│   ├── .gitkeep
│   └── current.log               # created at the first event
└── content/                      # optional, created on demand; referenced artifact content
    ├── rfc-0000.md
    └── evidence/                 # Phase 1: content-addressed evidence files, created on demand
        ├── captures/<sha256-hex>
        ├── streams/<sha256-hex>
        ├── outputs/<sha256-hex>
        ├── results/<sha256-hex>
        └── reports/<sha256-hex>
```

`.functor/runs/` (also on demand, not repository state) holds one lease file per incomplete run and one short-lived lock per request id being recorded ([ADR-0013](../adr/ADR-0013-run-lifecycle-and-evidence-persistence.md), [ADR-0016](../adr/ADR-0016-evidence-files-and-repair.md)). Like `.functor/lock` it should be git-ignored.

`functor init` creates `.functor/`, `.functor/repository.toml`, `artifacts/`, `relationships/` and `events/`, plus `.gitkeep` files in the three empty directories so an empty repository survives a git commit. `content/` is created the first time it is needed. `.gitkeep` files are ignored by the loader.

Required for a valid repository (rule `V0014`): `.functor/repository.toml`, `artifacts/`, `relationships/`. The `events/` directory is recommended but not required, because events are not authoritative state.

## `.functor/repository.toml`

```toml
id = "repo_01J9Z3JX9T8S7R6Q5P4N3M2K1H"
name = "Functor Core"
description = "Core RFC set"
format_version = 1
created = 2026-10-12T18:00:00Z
```

| Field | Required | Notes |
|-------|----------|-------|
| `id` | yes | `repo_<ULID>`, generated by `init`, immutable (RFC-0015 stable identity) |
| `name` | yes | defaults to the directory name |
| `description` | no | |
| `format_version` | yes | integer, MVP = 1. Governs [artifact-format.md](artifact-format.md) and this layout |
| `created` | yes | |

Other `.functor/` files from earlier drafts (`capabilities.toml`, `extensions.toml`, `settings.toml`) are **not** part of the MVP. They are reserved names; the loader ignores them.

## `artifacts/`

One file per artifact: `artifacts/<artifact-id>.toml` (ADR-0006). Format in [artifact-format.md](artifact-format.md).

## `relationships/`

One file per relationship: `relationships/<relationship-id>.toml`.

```toml
id = "rel_01J9Z3KQ0A1B2C3D4E5F6G7H8J"
type = "depends_on"
source = "art_01J9Z3K8M2Q7X4V6B5N1R0T8WD"
target = "art_01J9Z3K0P4Q5R6S7T8V9W0X1Y2"
created = 2026-10-12T18:05:00Z

[metadata]
note = "RFC-0001 builds on the vision"
```

| Field | Required | Notes |
|-------|----------|-------|
| `id` | yes | `rel_<ULID>`; equals the file stem (`V0017`) |
| `type` | yes | snake_case; see [ADR-0007](../adr/ADR-0007-relationship-types.md) |
| `source` | yes | artifact **id** (never slug or path) |
| `target` | yes | artifact **id** |
| `created` | yes | UTC timestamp |
| `metadata` | no | same typing rules as artifact metadata |

Relationships are immutable in the MVP. New relationship files use the same canonical form as artifacts (key order: `id`, `type`, `source`, `target`, `created`, then `[metadata]`).

## `events/`

`events/current.log` is an append-only JSON Lines file, one event per line (see [event-model-mvp.md](event-model-mvp.md)). Events are informational and **not** authoritative state: deleting the log never loses artifacts or relationships. Teams that commit repositories to git typically add `events/current.log` to `.gitignore`; `functor init` does not modify `.gitignore`.

`events/archive/` holds rotated logs, `events-<first-seq>-<last-seq>.log` with sequence numbers zero-padded to 12 digits. The log is rotated at 10 MiB and only the 10 newest archives are kept ([ADR-0008](../adr/ADR-0008-event-log-rotation.md)). Archives, like the log, are informational and are ordinarily git-ignored together with `events/current.log`.

## `validations/` (reserved)

RFC-0007 allows validation results to be persisted. `functor validate` still prints its report and appends a `validation.completed` event carrying the summary. Phase 1 persists a report only through the opt-in recorder, as a `validation_report` artifact with its document in `content/evidence/reports/` ([ADR-0015](../adr/ADR-0015-validation-report-persistence-and-events.md)); the directory name `validations/` stays reserved and unused.

## Reserved and Future Names

```text
indexes/  cache/  executions/  snapshots/  exports/  validations/  extensions/
```

Repositories must tolerate additional directories and files at the root that the MVP does not know about. Unknown files **inside** `artifacts/` and `relationships/` that are not `*.toml` or `.gitkeep` raise warning `V0016`.

## Portability Rules

- All names are ASCII and use only `[A-Za-z0-9_.-]`, so no escaping problem arises on Windows, macOS or Linux.
- Do not rely on case sensitivity or symbolic links. Ids are uppercase ULIDs after the lowercase prefix, so two distinct ids cannot collide on a case-insensitive filesystem.
- Paths stored in files always use `/`.
- Maximum single entity file size accepted by the loader: 2 MiB.

## Git Friendliness

- Entity-per-file makes diffs and merges local to the changed entity.
- Canonical form for new files and in-place updates for existing ones prevent spurious diffs.
- Suggested `.gitignore` entries: `.functor/lock`, `events/current.log`.
