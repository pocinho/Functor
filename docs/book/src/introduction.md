# Introduction

Functors is a Rust-based MVU-first editor and computational notebook designed for
exploration, creativity, and agent-assisted workflows.

It blends four pillars:

1. **MVU Core** — deterministic, testable UI logic.
2. **Custom Rendering Surface** — GPU-accelerated text and cell rendering.
3. **Notebook Cells** — executable blocks for computation, visualization, and narrative.
4. **Agent Integration** — local or remote LLMs that assist with refactoring, exploration, and automation.

Functors aims to be a long-term personal tool: a programmable notebook, a code
editor, and an agentic workspace unified under a single architecture.
