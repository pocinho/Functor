# Welcome to Functor

**Functor** is a coherent desktop workspace for editing and working with
documents. Its default implementation direction is a Tauri-hosted HTML
interface with Monaco as the code editor and Rust as the document-state and
native-effects layer.

This book describes the user-facing direction and the limited workflows
currently available in the Tauri transition build. It is not a promise that
the application is production-ready or available as a general installer.
